Cyber Threat Attack and Mitigation Simulation

Objective
At the end of this activity, learners should be able to:
Identify different types of cyber attacks
Analyze real-time security scenarios
Apply correct mitigation strategies
Understand how logs and alerts work in a SOC environment

Access the simulation here:
 👉 https://adovm-ctm-sim.netlify.app/

Instructions
Part 1: Access the Simulator
1. Open the link provided above

2.Enter the following:
⚬ Learner Name
⚬ Cyber Handle (your alias in cybersecurity)

3.Click Start

Part 2: Perform the Simulation
1. You will be given 10 cyber attack scenarios

2.Each scenario includes:
⚬ Attack description
⚬ Severity level (Critical / Medium)
⚬ Multiple mitigation options

1. For each scenario:
⚬ Read carefully
⚬ Analyze the attack
⚬ Choose the best mitigation action
⚬ Review the attack explanation after answering
Note: Each question has a time limit

Part 3: Analyze Results
After completing all scenarios, review your:
• Score
• Rating (Beginner / Intermediate / Advanced / Expert)
• Logs Panel (your actions and results

Part 4: Reflection Questions
Answer the following:

1. What type of attack did you find most difficult? Why?

2.Which mitigation strategy did you use most often?

3.How did the logs panel help you understand the attack?

4.Why is quick decision-making important in cybersecurity?

5.What will you improve next time?
Output / Submission
Submit the following:
• Screenshot of your Final Report (Score & Rating)
• Screenshot of Logs Panel
• Answers to the Reflection Questions
